# 系统架构与数据流

## 上位机主流程

`main1.py` 是正式入口。一次停车点流程如下：

1. 将机械臂停在安全扫描位。
2. 底盘摄像头检测黑线，误差稳定后连续发送 `0x07` 控制帧。
3. STM32 完成一段定时底盘移动并返回 `0x07`。
4. 释放底盘摄像头，启动 RealSense 扫描。
5. 机械臂依次到达配置的扫描层，在每层执行 YOLO segmentation。
6. `vision.py` 将果梗 mask 对应深度转换为三维点云，筛选合理深度簇并执行 PCA。
7. 由 `P1/P2` 中心得到相机三维剪切点，再通过 `calibration.py` 转换到机械臂坐标系。
8. `pick1.py` 生成预瞄、旋转、进刀、闭合、安全回退和释放动作。
9. `robot.py` 编码串口帧并等待 STM32 反馈。
10. `run_recorder.py` 保存日志、图片和 HTML 报告。

## 视觉定位

核心定位不读取检测框中心的单个深度值，而是使用整条果梗 mask：

```text
RGB 图像
  -> YOLO segmentation mask
  -> 与深度图对齐
  -> mask 内有效深度像素反投影为相机三维点
  -> 深度簇与场景共识筛选
  -> 深度截尾和空间离群点过滤
  -> PCA 主轴拟合
  -> P1、P2 和中心点
  -> 手眼刚体变换
  -> 机械臂剪切坐标
```

这能显著降低细果梗中心像素落到背景、导致整组三轴坐标偏移的问题。

## 手眼变换

`calibration.py` 使用：

```text
P_robot = R * P_camera + T - Te0 + Te
```

- `R`：相机坐标系到机械臂坐标系的三维旋转矩阵。
- `T`：固定拍照位下的平移向量，单位厘米。
- `Te0`：采集标定数据时的固定拍照位。
- `Te`：当前图像对应的机械臂拍照位。

当前矩阵由 12 个空间点通过刚体最小二乘拟合得到。与旧的三点法相比，多点拟合能平均测量噪声，并可使用独立验证点评估泛化误差。

## 控制器分工

| 控制器 | 主要职责 |
| --- | --- |
| Windows/Python | 视觉、定位、动作规划、流程状态、日志 |
| STM32F103C8 | 串口协议、三轴 CAN、旋转关节、底盘 CAN、RS485 转发、看门狗和 ACK |
| AT89C52 | 接收 `0x01/0x02`，输出双舵机 PWM，回显命令字节 |

## 并行动作

`send_rotate_and_robot_position()` 先发送 `0x05`，默认等待 50 ms 后发送 `0x04`，再统一等待 `0x05` 和 `0x04`。该设计让耗时较短的旋转与三轴移动重叠，但不改变机械臂到位判定逻辑。
