# 串口通信协议

## 上位机到 STM32

串口参数为 `115200 8N1`。命令统一为 15 字节：

```text
FF  CMD  DATA[12]  FE
```

多字节整数均为 little-endian。

### `0x04` 机械臂坐标

```text
FF 04 X(int32) Y(int32) Z(int32) FE
```

Python 将厘米值乘以 1000 后发送。例如 `35.822 cm` 发送为 `35822`。STM32 除以 100 得到毫米值，即 `358.22 mm`，再换算为各轴脉冲。

STM32 只等待本次确实需要移动的轴；未移动轴直接视为已到位。三轴闭环步进驱动器通过 CAN 返回到位帧后，STM32 置位 `xReached/yReached/zReached`。

### `0x05` 末端旋转

```text
FF 05 ANGLE(int32) 00 00 00 00 00 00 00 00 FE
```

角度乘以 100 后发送，支持负数。例如 `-25.50°` 发送 `-2550`。当前上位机和 STM32 均按有符号 `int32` 解析，不允许在 Python 端取绝对值。

### `0x06` 末端舵机动作

```text
FF 06 ACTION 00 00 00 00 00 00 00 00 00 00 00 FE
```

- `ACTION=0x01`：张开。
- `ACTION=0x02`：闭合。

STM32 通过 USART2/RS485 将动作字节发送给 AT89C52。

### `0x07` 底盘循迹误差

```text
FF 07 ERROR(int16) 00 00 00 00 00 00 00 00 00 00 FE
```

Python 在定时移动期间持续发送黑线横向误差。STM32 更新底盘 PID，并维护命令年龄和定时移动状态。

## STM32 到上位机

| 返回 | 含义 |
| --- | --- |
| `04` | 本次需要移动的机械臂轴均收到 CAN 到位反馈 |
| `05` | 旋转命令已下发；当前不是独立物理到位反馈 |
| `06` | 末端动作下发并固定等待约 1 秒后返回 |
| `07` | 本次底盘定时移动结束 |
| `E4 STATUS` | 机械臂移动异常及状态位 |
| `EE` | 旋转角超过 STM32 内部允许范围 |

`E4` 后的状态字节：

| 位 | 值 | 含义 |
| --- | --- | --- |
| bit0 | `0x01` | X 轴已到位 |
| bit1 | `0x02` | Y 轴已到位 |
| bit2 | `0x04` | Z 轴已到位 |
| bit6 | `0x40` | CAN 发送失败 |
| bit7 | `0x80` | 等待到位看门狗超时 |

## STM32 到 AT89C52

USART2 参数为 `9600 8N1`，RS485 半双工：

- `0x01`：舵机张开/复位动作。
- `0x02`：舵机闭合动作。

AT89C52 收到字节后回显同一字节。当前 STM32 的 `0x06` 上位机反馈主要依赖固定延时，不等同于带位置传感器的闭环到位确认。

## CAN 并发约束

STM32 向机械臂发送连续位置分片和同步帧时，底盘 TIM4 保活发送会短暂避让；避让期间只置 `Chassis_Keepalive_Pending`，机械臂 CAN 突发结束后立即补发底盘保活。该机制用于避免两类 CAN 帧并发破坏机械臂命令，同时防止底盘因长期收不到保活而退出自动模式。
