# 标定与安全操作

## 多点手眼标定

### 准备

- 在末端旋转中心安装细针，针尖位置必须固定。
- 准备 3～5 cm 的平面标记片，针尖接触点与相机点击点必须是同一个中心。
- 选择一个固定拍照位，整个标定过程中不得改变相机安装姿态、拍照位或针的位置。
- 规划安全返回路径：从标定点先只让 X 轴回退，再三轴移动到固定拍照位。

### 采集

```powershell
cd host_pc
python hand_eye_calibration_multi_point.py
```

1. 输入固定拍照位。
2. 输入针尖的机械臂目标坐标。
3. 普通点直接回车参与拟合；输入 `V` 的点只用于独立验证。
4. 针尖到位后固定标记片，人员离开运动范围。
5. 程序先执行 X 轴安全回退，再回固定拍照位。
6. 对同一标记中心连续点击 3 次并确认。
7. 标定点应覆盖实际工作空间的近、远、高、低和左右区域。

建议至少 12 个拟合点和 3 个独立验证点。验证点不能参与求解，否则无法评价新位置上的真实误差。

### 使用结果

脚本生成 `calibration_generated.py` 和 JSON 报告。先检查：

- 标定内点三维 RMSE；
- 每个独立验证点的 X/Y/Z 误差；
- 最大误差是否小于刀口允许容差；
- 是否存在某一方向持续同号偏差。

满足要求后再用候选矩阵替换 `host_pc/calibration.py`。启用新矩阵时，将旧的临时 Y/Z 补偿先设为 0，避免重复补偿。

## 空载验收

正式装刀前依次验证：

1. RealSense 彩色和深度流稳定，模型能输出果梗和主茎 mask。
2. 置信度阈值图中的实例编号与最终定位图一致。
3. 使用标定针验证至少 5 个未参与标定的位置。
4. 单独发送 `0x04`，确认三轴到位和 `0xE4` 状态解析。
5. 单独发送正、负 `0x05`，确认物理方向和 `±90°` 硬限制。
6. 断开刀片动力测试 `0x06` 张开和闭合顺序。
7. 抬起底盘或留出空场地，验证黑线丢失和起步稳定保护。

## 每次实验前

- 复测静刀尖、动刀尖到旋转中心的距离并更新配置。
- 核对串口号、底盘摄像头编号、扫描点和释放区间。
- 检查相机支架无松动；如有位移，重新标定。
- 检查步进驱动器、CAN 终端电阻、RS485 极性和公共地。
- 清空运动空间，确认急停有效。
- 先执行一个扫描点和一个空载采摘循环，再开始连续流程。

## 异常处理

- 收到 `E4`：记录状态字节，区分未到位轴、CAN 发送失败和看门狗超时，不要直接重复高速动作。
- 旋转方向异常：先断开刀片，在小角度下核对 `END_EFFECTOR_CLOCKWISE_SIGN`，禁止放宽 `±90°` 限制来绕过方向问题。
- 三维点明显异常：检查 mask 点云数量、深度簇、PCA 线性度和手眼矩阵，不要只依赖坐标限幅继续采摘。
- 底盘起步大幅转向：检查黑线稳定门槛、相机曝光、电脑性能和 USB 带宽。
