# AT89C52 双舵机末端固件

## 目标平台

- MCU：AT89C52。
- 工具链：Keil C51。
- 晶振/串口配置：代码按 11.0592 MHz、9600 bps 配置 UART。
- 工程文件：`project.uvproj`。

## 工作方式

AT89C52 从串口接收单字节动作，也可读取外接按键：

- `0x01`：上舵机复位/张开。
- `0x02`：上舵机转到目标位置/闭合。
- `0x03`：下舵机复位。
- `0x04`：下舵机转到目标位置。

Timer0 中断将两个舵机 PWM 交错输出。每个舵机使用高电平脉宽与剩余低电平组成约 20 ms 周期；主循环使能约 1 秒 PWM 后关闭输出并拉低信号脚。串口中断把收到的字节写入 `KeyNum2`，并回显同一字节。

## 编译

1. 使用 Keil C51 打开 `project.uvproj`。
2. 确认目标器件为 AT89C52。
3. 根据实际机械限位复核 `main.c` 中的 `start`、`end1`、`end2`。
4. 编译并烧录。

`prebuilt/project.hex` 是本快照的预编译文件。舵机连杆、齿轮、刀片或安装角改变后，必须低速重新标定脉宽，不能直接沿用旧限位。
